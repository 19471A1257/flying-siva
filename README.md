# Flying Siva
A responsive, tap-to-fly browser game featuring Siva. Built with HTML, CSS and Canvas JavaScript. No build or dependencies required.

## Play
Tap/click the game or press Space / Arrow Up to fly. Dodge the pipes. P pauses, M toggles optional synthesized sound. Personal best is saved in localStorage on your device.

## Run locally
Run `python3 -m http.server 3000` in this directory, then open http://localhost:3000.

## Deploy to Vercel
Import this repository, select **Other** as the framework, leave the build command empty, and use the repository root as the output directory.

The supplied portrait is rendered with browser cropping; the original photo is preserved in assets/siva.jpeg.
